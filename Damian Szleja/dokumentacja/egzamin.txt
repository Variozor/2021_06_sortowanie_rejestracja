DOKUMENTACJA EGZAMINU INF.04 - 2021
Autor: Damian Szleja

NARZĘDZIA
System przygotowania i testów: Ubuntu 24.04.3 LTS.
Środowisko pracy: edycja plików źródłowych i terminal Bash; kompilator OpenJDK 17.0.20.
Języki: Java, C# i XAML (XML).
Biblioteka interfejsu: .NET MAUI dla aplikacji mobilnej.

WERYFIKACJA
Konsola: skompilowana w Java 17 i uruchomiona; testy zakończone poprawnie.
Mobilna: projekt .NET MAUI, C# i XAML. Sprawdzono składnię XML. Próba użycia dotnet zakończyła się komunikatem command not found. Brak .NET SDK, Android SDK i emulatora uniemożliwia kompilację oraz emulację w tym środowisku. Nie dołączono pliku APK.
Emulator użyty: brak. Do uruchomienia: emulator Android w Visual Studio lub własny telefon.

DOKUMENTACJA METOD
sortuj() - sortuje pole liczby malejąco przez wybieranie; zwraca void.
szukajMaksimum(poczatek) - zwraca indeks największej liczby od wskazanego indeksu do końca tablicy. Metoda prywatna.
